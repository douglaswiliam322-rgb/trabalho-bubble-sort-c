## Descrição do Problema e Objetivo
Este projeto foi desenvolvido em linguagem C para resolver a necessidade de um supermercado que precisa organizar os preços de 10 produtos do menor para o maior valor, facilitando a visualização rápida por parte dos clientes ou funcionários.

---

## Como funciona o Bubble Sort
O **Bubble Sort** (ordenação por bolha) é um algoritmo baseado em comparações. Ele percorre o array várias vezes, comparando elementos adjacentes (pares vizinhos). Se estiverem na ordem errada, ele realiza a troca de posições. O processo se repete até que todo o conjunto esteja ordenado.

## Como Compilar e Executar
1. Clone o repositório ou baixe o arquivo `main.c`.
2. Abra o terminal na pasta do arquivo ou utilize um compilador online de C.
3. Compile o programa: `gcc main.c -o programa`
4. Execute: `./programa`
